# 主支线与目标系统 (Quest & Objective System) 设计文档

## 1. 系统定位与核心理念

主支线与目标系统（以下简称“本系统”）是 LAE 个人自我调节系统的核心组成部分，直接承载了“**分析→预测→干预**”的闭环理念。

它的核心定位是将用户长期的个人愿景、中期的具体目标和近期的日常行动进行结构化关联，旨在解决以下问题：
* **目标模糊化**：将宏大的、模糊的追求（如“提升自我”）拆解为清晰、可执行的路径。
* **行动与目标脱节**：确保每日的精力投入都能够服务于核心目标，避免偏离航道。
* **缺乏动态调整**：为未来引入基于个人状态的动态任务推荐与干预打下基础。

本系统是 LAE 从一个被动“记录工具”升级为主动“干预引擎”的关键。

## 2. 核心元素定义

为了结构化地管理个人目标，我们定义了以下核心元素：

* **主支线 (Quest)**
    * **定义**：代表一个长期、持续关注的生活或成长领域。它通常没有明确的截止日期，是一个宏观的分类标签。
    * **示例**：“13-学习与研究（硕士）”、“31-运动与健康”。

* **目标 (Objective)**
    * **定义**：在某个“主支线”下设立的、具体的、可衡量的、有时间限制的中期成就。它是连接宏伟蓝图与日常行动的桥梁。
    * **示例**：“月底完成奖学金面试”、“八月引体向上反手突破5个”。

* **日程 (Schedule/Event)**
    * **定义**：为实现某个“目标”而安排的、有明确起止时间的具体行动。这是任务执行的最小单元。
    * **示例**：“8月12日上午9点到11点，进行数据分析方法文献的梳理”。

* **作息规则 (Routine)**
    * **定义**：独立于具体“目标”的、周期性（通常是每日）的习惯性活动。其目的是维持个体的基本状态和生命节奏。
    * **示例**：“每天早上8点提醒：活动身体+晒太阳”、“每晚23:00提醒准备睡觉”。

## 3. 管理目标与机制（上层设计）

### 3.1 管理目标
* **目标结构化**：建立“主支线 → 目标 → 日程”的清晰层级，让所有行动都有迹可循。
* **进度可视化**：能够直观地看到在各个主支线上的投入与进展。
* **（未来愿景）动态规划与推荐**：最终，系统将能够根据个体的状态（精力、情绪等）、时间、地点等上下文，智能推荐当天最适合进行的“日程”，在保证“目标”进度的同时，最大化个体的行动效率与幸福感。

### 3.2 管理机制
* **层级化管理**：所有“日程”都应尽可能关联到一个“目标”，所有“目标”都必须从属于一个“主支线”。
* **（未来愿景）约束与规则引擎**：未来将引入规则引擎，允许用户定义个人化的行动约束。例如：“高烧脑活动（如写代码）一天累计不超过4.5小时，连续时长不超过90分钟”、“‘学习与研究’主支线下的活动，每日用时应在60分钟到3小时之间”。

## 4. 子系统设计

本系统由多个子系统构成，在开发上分阶段实现。

### 4.1 日程管理子系统 (Schedule Management Sub-system)
* **功能描述**：作为本系统最基础、最核心的子系统，它负责对“日程”和“作息规则”的创建、管理和执行。它是用户与系统进行每日规划与互动的主要入口。
* **核心功能**：
    * **日程创建与规划**：支持创建具有明确时间、内容并关联到特定“目标”的“日程”。
    * **作息规则定义**：支持用户定义固定的、每日或每周循环的“作息规则”。
    * **数据接口**：为其他模块（尤其是提醒模块）提供结构化的时间、事件数据。
    * **（未来规划）视图与看板**：提供日历、列表等多种视图，方便用户回顾与规划。

### 4.2 （未来规划）进度分析与回顾子系统
* **功能描述**：负责对已完成的“日程”和“目标”进行数据分析，量化在各个“主支线”上的时间和精力投入，生成回顾报告，为下一阶段的规划提供决策支持。

### 4.3 （未来规划）智能推荐与干预子系统
* **功能描述**：本系统的“大脑”。它将集成 LAE 系统的所有数据源（状态问卷、被动传感器数据等），通过预设的规则和未来的机器学习模型，动态生成每日的“日程”推荐，并执行主动的干预措施。

## 5. 与LAE核心模块的交互

### 5.1 提醒模块 (Reminder Module)
* **交互关系**：提醒模块是 LAE 系统的一个基础服务，而“主支线与目标系统”是该服务最主要的**调用方**。本系统为提醒模块提供了需要提醒的“内容”和“时间”。
* **在本系统中的具体表现形式**：
    * **日程提醒**：对“日程”中设定的开始时间进行准时提醒。这是最基本的形式。
    * **作息提醒**：对“作息规则”进行固定时间的提醒，如起床、睡觉等。
    * **方向感激励提醒**：在特定时间（如清晨），主动推送当天的关键“目标”或“主支线”重点，以提供动力和方向感。
    * **（未来愿景）智能干预提醒**：由智能推荐干预子系统触发的、基于复杂逻辑判断的提醒。例如，在深夜检测到用户在宿舍长时间使用娱乐应用，系统会判断其可能因焦虑拖延而未洗漱，从而弹出“该去洗澡了，不要陷入不当手机使用”的提醒，若提醒被多次忽略，可升级为锁屏等强制干预。
